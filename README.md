# 🌟 स्वामी विवेकानंद शाखा – तासिका विभाग

> **सेवा • शिक्षण • संस्कार • समाजकार्य**

A PHP and MySQL based web application developed for managing the **Taasika (तासिका) Department** of **Swami Vivekanand Shakha**.

The system provides a simple digital platform for student registration, student management, attendance, study resources, MCQ activities, test papers, monthly reviews and photo albums.

---

## 📌 About The Project

The **Swami Vivekanand Shakha – Taasika Management System** is designed to digitally organize the educational activities of the branch.

The main dashboard provides quick access to student-related services, attendance, study activities, MCQ games, monthly reviews and the branch album.

The dashboard also displays dynamic information such as:

- Total registered students
- Today's present students
- Branch establishment information
- Student registration
- Attendance
- Study
- MCQ Game
- Monthly Review
- Album

---

# 🎯 Project Objectives

The main objectives of this project are:

- 👨‍🎓 Manage student registration
- 👥 Maintain student information
- ✅ Record daily attendance
- 📊 Generate attendance reports
- 📚 Provide study resources
- 🎮 Conduct MCQ activities
- 📝 Provide test papers
- 📅 Maintain monthly reviews
- 🖼️ Display branch activity photos
- 📱 Provide an easy-to-use web interface
- 🗄️ Store information using MySQL database
